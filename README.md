# NOORX
An all-in-one AI platform with chat, voice, image, video and coding tools.
## 🚀 About NOORX
NOORX is an all-in-one AI platform designed to bring powerful AI tools into one place.

## ✨ Planned Features
- AI Chat
- AI Voice Assistant
- AI Image Generation
- AI Video Generation
- AI Coding Assistant
- Web Search

## 👑 Owner Access
The project owner will have full administrative access.

## 💎 Premium Access
Premium features will be available to other users through paid plans.

## 📱 Project Goal
Build a mobile-friendly AI platform that is simple and accessible.
